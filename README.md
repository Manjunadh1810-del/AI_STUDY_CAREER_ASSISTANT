# 🤖 AI Study & Career Assistant

An AI-powered assistant designed to help students with learning, career guidance, interview preparation, skill development, and academic support using Google's Gemini AI.

---

## 📌 Overview

AI Study & Career Assistant is an intelligent application that provides instant answers to academic questions, study guidance, career recommendations, and learning support. The system leverages Generative AI to assist students in improving their knowledge, productivity, and career planning.

This project aims to make education and career guidance more accessible through an interactive AI-powered platform.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/AI_STUDY_CAREER_ASSISTANT.git
cd AI_STUDY_CAREER_ASSISTANT
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/Mac:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 Configure API Key

Create a `.env` file and add your Gemini API Key:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

---

## 🔍 How It Works

1. User enters a question.
2. The query is sent to Gemini AI.
3. Gemini processes the request.
4. AI generates a response.
5. The response is displayed instantly.
